## 간략 소개 (자기소개 요약)

영업·배송·물류·전기자전거 정비 현장에서 9년간 일했습니다. 쿠팡 풀필먼트 냉동창고에서 리치 지게차로 상·하차와 적재를 하며, 쌓는 일이 얼마나 반복적인지, 설비 하나가 멈추면 일 전체가 멈춘다는 것을 몸으로 겪었습니다.

이후 대한상공회의소 인천인력개발원 로봇활용 첨단 생산시스템 과정(2026.03~10, 923시간)을 수료했습니다. MELSEC-Q로 MPS 공압 시퀀스를 직접 작화했고, DENSO 6축 로봇을 PLC 스트로브·커맨드 신호로 원격 기동해 랙에 층별로 적재하는 실습을 했습니다. 8인 팀 졸업 프로젝트(스마트팩토리 FMS)에서는 기구 설계, 솔밸브·근접센서 전장 시험, PLC–ESP32 절연 회로를 맡아 무동력 롤러의 공급 불량을 40회 중 25회에서 0회로 줄였습니다.

ABB 로봇은 아직 다뤄 보지 않았지만, DENSO에서 신호 하나하나를 매뉴얼로 확인하던 방식으로 빠르게 익히겠습니다. 대도의 로봇 적재·자동화 라인 설치와 시운전 현장에서 PLC와 로봇을 함께 책임지는 엔지니어로 성장하고 싶습니다.

## 스킬 순서 (대도용 추천)

PLC → 로봇 → EPLAN → Solidworks → Digital Twin → DB → 컴퓨터비전 → DeepLearning → 3D프린팅 → 생성형 AI

설치·시운전 직무라 PLC·로봇·전장(EPLAN)을 앞으로 올리고, 비전·딥러닝은 뒤로 내렸습니다. 각 스킬 설명 문구는 기존 공통 이력서 그대로 써도 됩니다.

### 로봇 (설명 문구 — 적재 실습을 앞으로)

DENSO VS060 6축 로봇 교육 이수: PLC에서 스트로브·커맨드·데이터 신호로 프로그램(Pro0~7)을 원격 기동해 랙에 워크를 층별 적재함. Approach·Depart·ChangeTool·오프셋 이동으로 픽업과 적재를 프로그래밍하고, 티칭 펜던트로 포인트를 티칭함. 체험판 WINCAPS III에 셀 기구를 직접 실측·모델링해 간섭을 시뮬레이션함. 졸업 프로젝트에서 Dobot Magician 4대를 Python(pydobot)으로 PC에서 직접 제어함.
